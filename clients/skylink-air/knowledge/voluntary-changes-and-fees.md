# Voluntary changes and change fees

## Change fee policy
If you choose to change a flight that is still operating, your booking includes one free change. The change must be to a flight on the same route. After the free change has been used, a change fee applies: 75 dollars for Economy, 40 dollars for Flex, and no fee for Business.

## Fare difference
Changes to a flight in a more expensive fare class require paying the fare difference. Changes are not possible within 2 hours of departure.

## Who can change a booking
Only the passenger named on the booking can request a change, after identity verification with the booking reference and last name.
